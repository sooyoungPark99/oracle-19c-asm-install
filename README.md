# ASM 환경에서 Oracle 19c 설치

ASM(Automatic Storage Management) 환경에서 Oracle 19c Single Instance 구축 가이드입니다.
VirtualBox 기반의 실습 환경에서 직접 설치하며 작성한 문서입니다.

---

## 환경 구성

| 항목 | 내용 |
|------|------|
| OS | Oracle Linux 7.9 |
| DB 버전 | Oracle Database 19c |
| 스토리지 | Oracle ASM |
| 가상화 | VirtualBox 7.0.18 |
| 메모리 | 8GB |

---

## 서버 구성

| VM 이름 | 호스트 이름 | 메모리 | 어댑터1 | 구성 방법 |
|---------|-----------|--------|--------|---------|
| psy_19C_asm | ora19c | 8GB | 어댑터에 브리지 | 리눅스 설치 |

---

## 스토리지

| 파일 이름 | 용량 | 타입 | 용도 |
|----------|------|------|------|
| psy_19C_asm | 100GB | Dynamic | 서버의 시스템 영역 |

---

## ASM 디스크 그룹

| 디스크 그룹 | 크기 | 용도 |
|------------|------|------|
| CRS | 3GB | 클러스터 레지스트리 |
| DATA | 20GB | 데이터 저장 영역 |
| RECO | 20GB | 복구 영역 |
